# hur skapar man ett repo utan terminalen

1. Börja med att skapa en ny mapp på ett ställe du kommer ihåg på din dator.

1. Öppna ett nytt fönster i VSC: File -> New Window.

1. Öppna mappen File -> Open Folder -> hitta mappen och klicka Open.

1. Lägg till lämplig gitignore, för c#-kodning:
    * på rad 1 obj/
    *på rad 2 bin/

1. Klickla på SOurce Control ikonen (okm du inte ändrat VSC settings) till vänster tredje ikonen uppifrån i sidomenyn.

1. Klicka på Initialize Repository

1. Skriv ett lämpligt commit-meddelande t.ex. "Added gitignore"

1. Klicka på Commit, sedan Save all & Commit changes i dialogrutan som kommer upp.

1. Klicka på Public Bransch

1. Välj sedan Publish to GitHub private repository om du inte vill andra ska kunna se ditt repo på GitHub, alternativt Publish to GitHub public repository om du vill andra ska kunna re repot

1. Vänta ett kort tag med filer förs över, sedan om du vill klicka på knappen Open on GitHub.
